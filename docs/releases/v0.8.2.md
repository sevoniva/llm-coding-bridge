# v0.8.2

`v0.8.2` hardens diagnostic logging after CodeQL identified two clear-text logging paths.

## Security

- The request-log fallback now emits only validated request metadata and HTTP status; it never copies fields from an upstream error object into stderr.
- The pre-content retry test failure handler no longer prints a complete error object, which could include sensitive test context.
- Regression coverage confirms that credential values, response bodies, error messages, and error codes stay out of the fallback log line.

## Validation

Focused request-log and pre-content retry tests, the security scan, secretlint, repository gate, release gate, full test suite, dependency audit, and package dry run pass before publication.

## Upgrade

```bash
npm install -g @sevoniva/llm-coding-bridge@0.8.2
```
