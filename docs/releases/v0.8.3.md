# v0.8.3

`v0.8.3` completes the CodeQL clear-text logging hardening from `v0.8.2`.

## Security

- The request-log fallback no longer reads any caller-provided details object. It emits only request context fields that are independently validated.
- The event-store path remains the only path that records status and canonical error codes, after the existing allowlist and record-shape checks.
- This removes the remaining CodeQL dataflow from API-key configuration errors to stderr while preserving the admin event timeline.
- The professional README documents this logging boundary together with the complete DeepSeek Harness setup and operations flow.

## Validation

Focused request-log tests, the full verification gate, and a fresh CodeQL scan pass before publication.

npm install -g @sevoniva/llm-coding-bridge@0.8.3
