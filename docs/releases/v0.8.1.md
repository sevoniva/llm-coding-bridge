# v0.8.1

`v0.8.1` replaces the README with a structured product and operations guide, including a first-screen DeepSeek Harness setup path.

## Documentation

- Reorganized the README around architecture, installation, configuration, protocol behavior, client setup, operations, security, and diagnostics.
- Added a concise custom-provider quick start for DeepSeek Harness in English and Chinese.
- Explicitly documented that the built-in official provider remains available and that Harness source changes are unnecessary.
- Surfaced the `translateThinkingToReasoningEffort` and `maxOutputTokens` route options next to the quick-start configuration.

## Validation

The published package is the same tested bridge implementation as `v0.8.0`; only package metadata and documentation changed for this patch release. The full verification gate and npm package smoke test pass before publication.
