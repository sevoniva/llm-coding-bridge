# v0.8.4

`v0.8.4` restores DeepSeek Harness compatibility with strict OpenAI-compatible Chat Completions upstreams.

## Compatibility

- Chat Completions requests now normalize the newer OpenAI `developer` message role to the broadly supported `system` role before forwarding upstream.
- The original client payload remains unchanged.
- Responses API conversion keeps its existing equivalent role normalization.
- This fixes upstream HTTP 400 responses when current DeepSeek Harness releases send their instruction message as `developer`.

## Validation

The focused chat compatibility and DeepSeek Harness suites, lint gate, complete test suite, static security scan, secret scan, repository and release gates, dependency audit, package dry run, and a real local DeepSeek Harness headless request pass before publication.

npm install -g @sevoniva/llm-coding-bridge@0.8.4
